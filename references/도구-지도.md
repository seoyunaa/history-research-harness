# 도구 지도 — tools/ 카탈로그

> 공개본 `tools/`에 들어 있는 도구 목록이다. 어떤 도구가 있는지 확인할 일이 생기면 이 파일을 먼저 읽는다.
> 도구의 사용 규율(무엇을 하드 FAIL로 막고 무엇을 GC로 두는지)은 `CLAUDE.md`가 정본이다 — 이 파일은 소재 목록이지 규칙이 아니다.
> 파일 실재는 `python tools/check_harness_hierarchy.py`가 검사한다. 도구를 더하거나 빼면 이 목록도 고친다.
> 각 도구의 사용법은 도구 파일 머리말(docstring)에 있다.

---

## 전체 카탈로그

```
tools/
├── 가드레일·검사
│   ├── verify.py                  ← 가드레일·GC 총괄(P-키·서지 화이트리스트·原文 미완·지리 출처·
│   │                                 관계형 외래키·마스터 좌표·면수/전거/연대 확인 미해결)
│   ├── verify_hook.py             ← 파일 수정 직후 verify.py를 조용히 돌리고 하드 FAIL일 때만 알리는 훅
│   │                                 (기본 꺼짐 — 켜는 것은 저자 결정)
│   ├── check_harness_hierarchy.py ← 위계·경계 검사(버전 스탬프 단일성·우선순위 선언·필수 참조 실재·
│   │                                 로컬 데이터 누출) — run_verify 편입
│   └── regression_traps.md        ← 모델 회귀 함정 배터리(바닥 B1~B4 기계 오라클 / 천장 C1~C4 사람 판정)
│                                     → 판정 기록은 references/이행-훈련.md §1.5
├── 문체
│   └── voice_match.py             ← 초안 문체를 style-profile-ko.md 실측 대역과 대조(참고급 GC)
│                                     + 레지스터·평이성 진단(의인화·철학투·은유·문제화 어휘)
├── 자료 반입·도서관(검색 위계 — 0~2차는 선택적 로컬 데이터층)
│   ├── ingest.py                  ← 보유 자료(PDF·docx·hwp 등) → provenance 프런트매터가 붙은 Markdown
│   │                                 (텍스트층 없는 스캔본은 변환하지 않고 [GAP: OCR필요]로 보고)
│   ├── _libconfig.py              ← 도서관 공통 설정(검색 위계 sources.txt·경로)
│   ├── library_index.py           ← 보유 자료 전문 색인(SQLite FTS5) → references/library/fulltext.db
│   ├── library_search.py          ← 전문 검색(위계 순서로 응답, 없으면 "3차(웹)로" 안내)
│   ├── endnote_sync.py            ← EndNote 라이브러리 → 보유원장 카탈로그(읽기 전용, 선택)
│   ├── refresh.py                 ← 도서관 갱신 묶음(있는 층만 갱신)
│   └── decode_qr.py               ← QR 이미지에서 URL/텍스트만 추출(방문하지 않음)
├── 관계형 데이터
│   └── build_db.py                ← 발췌 카드 CSV(관찰·장소·범주)에서 SQLite DB를 재생성(CSV가 진실, DB는 파생물)
├── 시각화
│   ├── suggest_visual.py          ← 시각화 위저드의 데이터 실측기(어떤 신호가 실재하는지 세고 유형을 추천)
│   ├── build_network.py           ← 인물·관계 주장 CSV → 재현 가능한 네트워크(정확 일치 결속, 미결속은 GAP 대기열)
│   ├── build_diachronic.py        ← 세대×가문 혼인 변천(세대는 친자 그래프의 기계적 거리로만)
│   └── georef.py                  ← 고지도·영인본 지오레퍼런싱(GCP 파일 → GeoTIFF + 매니페스트)
└── 최종 산출(한국어)
    ├── md2hwpx.py                 ← 원고 md → 투고 스타일 hwpx(순수 구조 변환·자기검증·AI잠정 라벨).
    │                                 투고 양식 .hwpx 템플릿은 사용자가 준비한다
    └── test_md2hwpx.py            ← md2hwpx 회귀 시험
```

## 도구별 상세가 따로 있는 것

- `tools/regression_traps.md` — 모델 회귀 함정 배터리(바닥 B1~B4 · 천장 C1~C4). 판정 기록은 `references/이행-훈련.md` §1.5.
- `references/hgis-지오레퍼런싱.md` — georef.py 워크플로와 GCP 양식.
- `references/시각화-참조.md` — 시각화 문법과 외부 자료 반입 규율.
- `references/local-data-layer.md` — 도서관 도구가 기대는 선택적 로컬 데이터층의 구조와 설치법.
