# 외부 자원 커넥터 레지스트리

> 역사 연구에 쓰는 공개 데이터베이스·게이지티어·디지털 서고를 하네스에 정박하는 목록이다. 절대 원칙(상속): **외부 결과는 전부 "발견/제안"이다.** 척추(카드·화이트리스트·마스터)에 들어가려면 **저자 확인 + 권위 판본/1차 사료 정박**을 통과해야 한다. 커넥터는 조회만 하고, 무엇을 채택할지는 저자가 정한다.
>
> ⚠ **아래 목록은 예시다 — `research-profile.md`의 분야·시대·지역에 맞게 고르라.** 쓰기로 한 자원은 `research-profile.md` §5에 적고, 이 표에는 분야에 맞는 자원을 더하거나 빼서 관리한다. 주소·접근 방식·이용 조건은 바뀔 수 있으므로 사용 전에 직접 확인한다.
>
> 공개본에는 개별 커넥터 조회 도구가 들어 있지 않다. 웹 화면이나 공개 API로 조회하고, 결과를 `_workspace/{논문}/` 작업표에 출처(자원명·URL 또는 ID·조회일)와 함께 적는다. 조회 스크립트를 직접 만들면 입력·명령·출력을 매니페스트에 남긴다.

## 두 계급 (자원은 이 둘로 갈린다)

1. **권위 DB**(학술 게이지티어·인물 DB 등): 구조적 조회로 마스터를 *제안* 채운다. 학계가 인정하는 계통이라도 마스터 기입은 저자 게이트다. 좌표·ID는 대조 후에만.
2. **발견 플랫폼**(원문 DB·디지털 서고·전문 검색): 원전·인물을 *찾는* 웹 도구(검색 위계의 3차). ⚠ 여기서 얻은 原文은 **반드시 권위 판본으로 검증**한 뒤에만 카드에 정박한다. 플랫폼 텍스트·OCR·스니펫을 그대로 단정하지 않는다. "어떤 판본인지 나중에 반드시 확인한다."

## 공통 후보 검토 절차

- 권위 DB 조회 결과는 한 작업표(예: `_workspace/{논문}/gazetteer_review.csv`)에 출처별로 모으고, 기존 `corpus/gazetteer-master.csv`와 대조한다. 절차는 `references/gazetteer-linking.md`.
- 모든 행은 처음에 `candidate`이며 자동 승급하지 않는다. 마스터는 저자 확인 뒤 저자가 고친다.
- 지도에 보이는 모든 좌표는 원천 CSV의 제안값이다. `[GAP:좌표]`는 화면 표시용 임시 좌표로 채우지 않는다.

## 0건의 의미

검색 0건은 "부재"의 증거가 될 수 있으나, 이체자·표기 이형·OCR 오류·검색 방식 때문일 수도 있다. 자형 이형과 다른 표기를 함께 돌린 뒤 해석한다(판단은 저자).

---

> 커넥터를 추가할 때는 이 표에 한 줄 더하고, 권위 DB면 마스터 제안 경로를, 발견 플랫폼이면 판본 게이트를 명시한다. 자동 확정은 없다 — 전부 저자 게이트.
