# references/library/sources.txt 양식 — 이 파일을 같은 폴더에 sources.txt로 복사해 고쳐 쓴다.
# sources.txt는 개인 로컬 경로를 담으므로 git에 올리지 않는다(.gitignore 대상).
#
# 읽는 도구(공통 파서 tools/_libconfig.py):
#   tools/verify.py          보유 자료 실재 대조(03_biblio_whitelist.md가 선언한 파일이 tier1 폴더에 있는가 — 정보)
#   tools/library_index.py   tier1 폴더 + EndNote PDF 전문 색인 → references/library/fulltext.db
#   tools/library_search.py  보유 자료 검색(0차 → 1차 → 2차, 없으면 3차 웹으로 안내)
#   tools/endnote_sync.py    EndNote 라이브러리 → references/library/catalog.json
#   tools/refresh.py         위 갱신을 한 번에
# sources.txt가 없으면 모든 도구가 안내 한 줄만 내고 건너뛴다(실패 아님).
#
# 형식: 한 줄에 `키: 값`. `#`로 시작하는 줄은 주석.
#       상대경로는 하네스 루트(이 저장소 최상위 폴더) 기준. 절대경로도 된다.
#       실재하지 않는 폴더는 건너뛴다(verify.py는 어떤 폴더가 없는지 알려 준다).
#
# 검색 위계:
#   0차 사료 등록부  core-library/catalog.yml (선택, 이 파일에서 설정하지 않음)
#   1차 tier1 폴더   저자가 지정한 보유 원문·PDF·추출 md 폴더            ← 아래 tier1:
#   2차 서지관리     EndNote 라이브러리의 첨부 PDF·서지(선택)             ← 아래 endnote:
#   3차 웹           source-verifier가 1·2차로 부족할 때만, 마지막에
#
# ── 1차: 저자 지정 우선 폴더 ──
# 여러 줄로 적거나, 한 줄에 콤마(,)·세미콜론(;)으로 여러 폴더를 적는다.
# 하네스 폴더 밖(형제 폴더)에 두는 것을 권장한다 — 저장소에 원문·PDF가 섞이지 않게.
tier1: ../my-sources
# tier1: ../my-sources/primary, ../my-sources/secondary
#
# ── 2차: EndNote 라이브러리(선택) ──
# endnote_sync.py가 읽을 EndNote .Data 폴더. 여러 줄 = 여러 라이브러리(첫 줄이 기준 라이브러리).
# 적지 않으면 2차층은 비활성(개인 기본 경로를 가정하지 않는다).
# endnote: ../my-library.Data
#
# ── 도서관 OpenURL 리졸버(선택) ──
# PDF 없는 서지의 도서관 원문 링크를 만들 때 쓰는 기준 URL(자격증명은 적지 않는다).
# openurl: https://resolver.example.org/openurl
