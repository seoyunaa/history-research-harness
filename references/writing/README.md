# writing — 글쓰기 근거 서목

하네스의 글쓰기 규칙이 기대는 글쓰기 안내서 11권의 서목이다. 내용 대부분(논증·구조·역사학 규범)은 **언어가 아니라 분과의 방법**이라 한국어·영어 원고에 함께 쓴다.

**하네스 안에서 작동하는 지침은 아래 파일들이고, 이 서목은 그 전거다:**

- `references/writing-craft.md` — 언어 중립 전개 규범(논지 시험·논증 조직·문단·전환·서사·결론·퇴고)
- `references/register-rules-en.md` + `references/citation-format-en.md` — 영어 실현·영어 전용 규칙
- `references/register-rules-ko.md` 10절이 craft를 상속 — 한국어는 저자 문체 프로파일(`style-profile-ko.md`)이 상위

**적용 레이어:** `05_적용가이드_비원어민_명료성.md` — 비원어민 저자가 영어 원고를 *고칠 때* 쓰는 명료성 우선 자기교정 가이드(한국어 L1 오류 카탈로그·they say/I say 템플릿 포함). 윤문·심사·집필(prose-writer, `lang: en`)이 register-en과 함께 참조한다. 목표는 과장된 수사가 아니라 논지의 깔끔한 전달이다.

규칙 파일과 서목·가이드가 어긋나면 규칙 파일이 우선한다(그리고 가이드를 고쳐 정합시킨다).

> 책별 요약·발췌 노트는 저작권 때문에 공개본에 넣지 않는다. 필요하면 각자 소장본에서 만들어 로컬에 두고, 원문 인용은 짧게 제한한다.

## 모듈별 소비 지점

- **1단계(question-sharpener)** — 논지 시험 3종은 `question-architecture.md` 1a절로 이식됨(근거: Belcher·Schrag·Booth).
- **3단계(structure-architect)** — 통과 시험 7번(논증 조직)의 근거는 Belcher; `lang: en`이면 서론 비중·historiography 압축(register-en 8절, 근거 Hayot·Swales).
- **집필(4–8단계, prose-writer)** — craft(공통) + register-{lang}(실현)이 작동층.
- **윤문** — 퇴고 순서·reverse outlining은 craft 8절; EN 문장 루틴은 register-en 10절과 05 가이드 7절.
- **심사** — 심사 지적의 근거 조회용(예: "서론이 왜 이렇게 긴가" → register-en 8절; "결론이 요약뿐" → craft 7절).

## 알려진 긴장 (봉합 안 함)

논지 공개 시점 — Booth·Belcher("서론에서 일찍·명확히") vs. Hayot("다 말하지 말라"). 하네스의 판단: 논증의 존재와 방향은 반드시 서론에서, 최종 형태의 완전한 전개는 아껴도 좋다. 심사 통과가 걸린 원고는 Booth 쪽으로.
