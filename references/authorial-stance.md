# authorial-stance.md — 저자의 기존 연구와 논지 (템플릿, 언어 중립)

> **이 파일은 비어 있는 양식이다.** 하네스를 쓰는 연구자(저자)가 자기 입장과 논저 목록을 채운다. 채우기 전에는 에이전트가 이 파일에서 아무 입장도 끌어오지 않는다. 빈칸을 모델이 추측으로 채우지 않는다.
>
> 새 글은 저자가 앞선 연구에서 세운 논지와 정합하게 쓴다. 한국어·영어 등 원고 언어와 무관하게 적용한다. 이 파일은 추상 명제가 아니라 저자의 실제 논저에서 뽑은 **구체적 논지**를 담는다.
>
> 상속처: prose-writer(논지 정합), question-sharpener(각도 우선 검토), structure-architect(자기겹침 차단 — 기존 논저의 핵심 주제로 장이 끌려가는지 경고), intro-reconciler, 윤문 모듈(논지를 뒤집지 않게).
>
> 논문 하나에서 대화 중 벼린 방향성·결정은 이 파일이 아니라 그 논문의 `_workspace/{논문}/_authorial_foundation.md`(`corpus/_authorial-foundation-template.md`)에 적는다. 이 파일은 논문을 가로지르는 **저자 전체의 입장**이다.

## 저자 정보 (선택)

| 항목 | 값 |
|---|---|
| 표기할 이름(언어별) | |
| 본인 논문 지시어 | 예: 한국어 "졸고", 중문 "拙稿", 영어 "my earlier article" |

공개 저장소에 올릴 때는 이 표를 비워 두거나 로컬 사본에만 적는다.

## 일관된 시각 (축 2~4개)

저자의 연구 전체를 관통하는 입장을 축마다 2~5문장으로 적는다. 각 축에 그 입장이 드러난 본인 논저를 아래 목록의 번호로 단다.

**1. {축 이름 — 한 줄 명제}**
{입장 서술: 무엇을 무엇으로 보는가, 무엇을 거부하는가, 그 근거가 된 사료·방법}. 근거 논저: {A1, A3}

**2. {축 이름 — 한 줄 명제}**
{입장 서술}. 근거 논저: { }

**3. {축 이름 — 한 줄 명제}**
{입장 서술}. 근거 논저: { }

> 쓰는 법의 예(내용 예시가 아니라 형식 예시): "후대 편찬 사료가 지운 행위자를 사료 비판으로 복원한다", "어휘의 출처보다 그 어휘가 수행한 제도적 기능에 주목한다", "제도의 규범 층위와 운용 층위를 구분한다" 같은 수준의 명제.

**보조 명제(선택)**: { }

## 방법적 서명

저자가 반복해 쓰는 방법을 적는다. 예시 항목(해당하는 것만 남기고 고쳐 쓴다):

- {예: 서로 다른 언어·계통 사료의 교차 비판 — 교차검증 사실을 본문에 명시}
- {예: 텍스트 비판과 인물지(prosopography)}
- {예: 물질 자료(인장·비문·출토물)의 통합}
- {예: 제도의 규범 층위와 실제 운용 층위의 구분}
- {예: 한계의 명시 — 사례의 대표성과 범위를 밝힌다}

## 본인 주요 논저

prose-writer는 아래를 근거로 인용하고 새 글을 그 위에서 잇는다. **서지가 확인된 것만 단정하고, 미확정은 표시한다. 모델은 이 목록을 추측으로 늘리지 않는다.** 인용할 때는 이 목록이 아니라 화이트리스트(`03_biblio_whitelist.md`)에 등록된 서지를 쓴다.

| 번호 | 구분 | 서지(투고지 표기법대로) | 상태 | 핵심 논지 한 줄 |
|---|---|---|---|---|
| A1 | 학위논문 / 게재 / 단행본 / 투고 중 / 미출판 | | 확인됨 / `[확인 필요]` | |
| A2 | | | | |
| A3 | | | | |

- **상태 표기**: 종면·권호·게재 여부를 별쇄본·DB로 확인하지 못한 항목은 `[확인 필요]` 또는 시작면 뒤 `ff.`로 둔다. source-verifier가 2단계에서 확정해 화이트리스트에 올린다. 확정 전에는 권·호·시작면까지만 쓰고 종면을 지어내지 않는다.
- **투고 중·미출판** 원고는 인용 근거로 쓰지 않고 정합성 참고로만 쓴다(본문 인용은 게재 후).

## 정합성의 한계 — 증거가 우선이다

관련된 본인 논문이 있으면 그 위에서 이어 가고 그 결론을 근거로 인용한다. 다만 **새 사료가 기존 입장을 뒤집으면 그 사실을 숨기지 않고 명시한다.** 정합성을 맞추려고 증거를 비틀지 않는다. 이는 절대 원칙의 직접 귀결이다.

## 선행연구에 대한 태도

- 선행연구의 주장은 그 연구가 실제로 한 바를 정확히 옮긴다. 약하게 세우거나 하지 않은 주장을 붙이지 않는다.
- 저자가 주로 대화하는 연구(연구자·논저)를 여기에 적어 둘 수 있다: { }. 이 목록도 서지 확인 전에는 인용 근거가 아니다.
- 어떤 학자의 입장을 확인할 수 없으면 단정하지 말고 표시한다. 사료를 지어내지 않는 원칙은 선행연구에도 똑같이 적용된다.
- 오류는 직접 지적하되 존중하는 어조를 유지한다.
- 기존 서술이 놓친 행위자나 시각을 대안으로 제시한다. 이것이 본고 기여점의 자리인 경우가 많다.
