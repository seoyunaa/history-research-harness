# 시각화 모듈 — 위저드 진입 (표·지도·네트워크·통시, 재현 가능)

절대 원칙(`CLAUDE.md`) 상속: **좌표·지명 비정·연대를 지어내지 않는다.** 좌표는 사료 P-키/고증 면수/게이지티어에 정박, 못 찾으면 `[GAP:좌표]`로 비우고 지도에서 뺀다.

## 0. 진입 위저드 — 바로 만들지 말고, 순서대로 묻는다

**0-a. 데이터부터 본다** (질문 전에 실측 — 추천의 근거는 저자의 감이 아니라 파일의 열):
```
python tools/suggest_visual.py <데이터파일> [<파일2> …]
```
이 실측기가 CSV/JSON/JSONL/스캔 이미지를 열어 신호(①lon/lat 좌표 열·값 채움 ②시간축 시기·세대·연도 ③관계 source/target·주장 ④스캔 이미지 ⑤수치 집계)를 세고, 유형을 근거와 함께 **추천**하며 방식 하위질문·다음 명령까지 인쇄한다. 좌표 열이 있어도 **값이 비면 `[GAP:좌표]`로 정직하게 보고**한다. 도구 없이 볼 때도 같은 5신호를 눈으로 확인한다.

**0-b. 질문 1 — 유형** (Claude Code에서는 `AskUserQuestion` 도구로, 실측기가 고른 추천안을 첫 선택지에 "(추천)" 표기. 그 밖의 도구는 같은 질문을 일반 텍스트로):
> 어떤 유형으로 만들까요? — **표 / 지도 / 네트워크·그래프 / 통시(시간 변화)**

추천 규칙(0-a 실측 기반 — suggest_visual이 자동 판정):
| 데이터 신호 | 추천 |
|---|---|
| lon/lat 값 채움 | 지도 |
| lon/lat 열은 있으나 값 비어 [GAP:좌표] | 지도(단, 좌표 정박 후) |
| source/target·주장(claims) 구조 | 네트워크 |
| 시기·세대·연도 열 + 집단 | 통시 |
| 수치 집계·비교·목록 | 표 |
| 픽셀(pixel_x/y) GCP · 스캔 지도 이미지 | 지오레퍼런싱 먼저 → 지도 배경 |
| 신호 복합(좌표+시간축 등) | 복수 추천 제시, 저자 선택 |

**0-c. 질문 2 — 방식** (유형 확정 후, 유형별 분기):

지도라면:
> 어떤 방식으로? — **① 코드 정적 지도**(pandas/geopandas — 빠른 검토·논문 도판 초안) / **② GIS 데스크톱 게재본**(예: QGIS — 저자 카토그래피, 하네스는 데이터층 geojson/csv만 준비) / **③ 웹 뷰어**(검색·필터·마커 상세 — 연구 탐색용, 사용자가 갖춘 뷰어 도구)

네트워크라면:
> **① 정적**(논문 도판+GEXF, `build_network.py`) / **② GEXF를 Gephi 등에서 손 탐색**(저자 작업, 결과는 매니페스트에 기록)

통시라면:
> **① 정적 막대**(세대×집단, `build_diachronic.py`) / **② 논문 폴더의 집계 스크립트**(명시 시기 열 기준 — 시기 배정 근거는 저자 책임)

표라면:
> **① markdown 표**(본문 삽입) / **② 관계형 쿼리**(`build_db.py` — "한 장소에 수렴하는 관찰" 등)

**0-d. 부가 설정** (한 번에 묶어서, 해당할 때만):
배경(없음/정합 고지도 GeoTIFF/판도 데이터) · 범위(bbox·지역·시기) · 상세 표출(근거·해설) · 산출 위치(`_workspace/{논문}/`).

**0-e. 실행** → §2 공통 규율 상속(매니페스트·검증 필수).

⚠ **과잉질문 금지**: 저자가 이미 유형·방식을 지정했으면("QGIS로 노선도") 질문 생략, 한 줄 확인 후 진행. 질문은 최대 2회(유형→방식), 부가 설정은 묶어서 1회.

## 1. 경로 지도 (유형 × 방식 → 도구)

| 경로 | 언제 | 명령 | 산출 |
|---|---|---|---|
| **진입 실측** | 시각화 요청을 받으면 먼저 | `python tools/suggest_visual.py <데이터파일>` | 신호 진단 + 유형 추천 + 방식 질문·다음 명령 |
| 지도·코드 정적 | 빠른 검토, 도판 초안 | 논문 폴더에 `fig{N}.py` 스크립트를 두고 실행(geopandas/matplotlib) | PNG/SVG+매니페스트 |
| 지도·GIS 게재본 | 게재 품질 | 하네스=데이터층(geojson/csv), 저자=GIS GUI 카토그래피, 프로젝트 파일·버전을 매니페스트에 | 인쇄 품질 PNG |
| 네트워크·정적 | 논문 도판, Gephi 손 탐색 | `python tools/build_network.py --persons … [--claims …] --out …` | GEXF+HTML+PNG/SVG+매니페스트 |
| 통시·정적 | 세대×집단 변천 막대 | `python tools/build_diachronic.py --persons … --claims … --out …` | 집계CSV(claim 역추적)+PNG |
| 지오레퍼런싱 | 스캔 고지도→배경 | `python tools/georef.py <스캔> <gcp.csv> <출력.tif>` (상세 `references/hgis-지오레퍼런싱.md`) | GeoTIFF+매니페스트 |
| 표 | 본문 표·관계형 집계 | markdown 직접 / `build_db.py` | 표(+쿼리 재현) |

데이터가 아직 CSV 계약이 아닐 때는 DB 모듈(`tools/ingest.py`, 게이지티어 조회)로 먼저 정리한다.

## 2. 공통 규율 (어느 경로든 상속)

1. **좌표는 마스터에서 상속** — `corpus/gazetteer-master.csv`의 `gm_id`. 없는 지명은 DB 모듈 정박(게이지티어 → 저자 게이트) 후 승급.
2. **논문별 좌표 화이트리스트** — `_workspace/{논문}/04_geo_whitelist.md`. 표준 노드 스키마 — **source 공란 = 하드 FAIL**.
3. **결속 규율**(네트워크·통시): 노드는 개체 CSV가 유일 원천, 이름 결속은 **정확 일치**만 — 실패는 `[GAP: 미결속]` 대기열(퍼지 매칭 금지). 상충 주장은 certainty 실선/점선으로 보존.
4. **시간축 反날조**: 세대=친자 그래프 기계적 거리, 명시 시기=저자 책임 — 해석적 시기 배정을 도구가 대신하지 않는다. 역법 환산이 걸린 연대는 카드의 환산 근거를 따르고, 없으면 `[GAP:연대]`.
5. **매니페스트 의무** — 산출물마다 ①생성 명령 ②환경 ③설명·주장 ④입력+SHA-256 ⑤한계(양식 `corpus/_figure-manifest-template.md`). 처리 이력은 `_provenance.md`.
6. **검증** — `python tools/verify.py`(geo_scan: 출처 공란 FAIL·매니페스트 GC).
7. **배경 고지도 한계 명기**: 회화식 고지도 정합본은 방위 오버레이 전용 — **거리·면적 분석 금지**를 매니페스트와 화면에 남긴다.
8. **정직한 부분 그림**: 표시한 데이터가 전체의 부분이면 도판 제목·푸터에 밝힌다.
