# registry.md — 사료 정체성 등록부 (템플릿)

> 1차 사료의 *정체성*을 담는다 — 서지, 판본, 권위 정본, 표기, 작성 시점, 편향, 전승. 原文은 담지 않는다. 原文은 논문별 발췌 카드(`_workspace/{논문}/passages/`)에 둔다.
>
> 모든 논문이 이 파일을 공유한다. 분야(시대·지역·사료 언어·연대 체계)는 `research-profile.md`가 정하고, 이 파일은 그 분야의 사료를 하나씩 등록한다.
>
> **이 파일의 모든 항목은 사용자 검증 대상이다.** 모델은 판본 사항·권차·면수·청구기호·작성 연도를 기억으로 채우지 않는다. 확인하지 못한 필드는 `[확인 필요]` 또는 해당 갭 마커(`[GAP:전거]`·`[GAP:연대]`)로 비운다. 서지를 확인하지 못한 사료는 등재하지 않는다. 잘못된 항목은 사용자가 고친다.

---

## 쓰는 법

1. 새 사료를 처음 인용하려 할 때(2단계) 먼저 여기에 등록한다. 등록은 서지를 확인한 뒤에만 한다.
2. 아래 「항목 양식」을 복사해 유형별 절(`## 사료 유형: …`) 아래에 붙이고 채운다. 유형 분류는 `research-profile.md` §4를 따른다.
3. 모르는 칸은 지우지 말고 `[확인 필요]`로 남긴다. 빈칸("아직 안 적음")과 "확인 안 됨"을 구별하기 위해서다.
4. 서명·인명 표기는 `references/glossary-master.md`와 논문별 `glossary.md`에 맞춘다(같은 대상은 한 표기로 고정).
5. 「성격과 편향」 칸은 `references/source-criticism.md`의 외적·내적 비판 항목을 따라 적는다.
6. 실물 파일의 소재·판본 계보·검색층 상태는 이 파일이 아니라 `core-library/`의 `source.yml`에 적는다(선택, 규약 `core-library/SCHEMA.md`). 여기에는 그 `source_id`만 남긴다.
7. 어느 논문이 표준 판본과 다른 판본·역본을 쓰면, 이 파일을 바꾸지 말고 그 논문 발췌 카드의 「위치」 칸에 판본을 따로 적는다. 연구자가 늘 쓰는 판본(상용본)이 정해지면 「권위 정본」 또는 「기타 판본·역본」 칸에 반영한다.
8. 원문 텍스트·OCR·웹 텍스트만 있고 권위 정본을 확인하지 못한 사료는 등록은 하되 「권위 정본」을 `[확인 필요]`로 두고, 확인 전에는 단정 인용하지 않는다.

## 항목 양식

```
### {약칭}
- 정식 서명: {원어 서명} / {표기(glossary 고정)}
- 사료 구분: 1차 (이 파일은 1차 사료 전용. 공구서는 맨 아래 별절, 선행연구·이론은 논문별 화이트리스트)
- 유형: {예: 편찬 연대기 / 행정·법제 문서 / 서신·일기 / 견문·여행기 / 비문·금석 / 문집 / 도상·지도 / 물질 자료}
- 언어·문자: {예: 고전 한문 / 중세 라틴어 / 아랍 문자 페르시아어}
- 저자·편찬자: {이름(표기)} — 모르면 "미상"이라고 적는다
- 작성·편찬 시점: {사료 자체의 연대 표기} → {서력} (환산 근거: {연표·역표·도구}) / 미확인이면 [GAP:연대]
- 권위 정본: {비판정본·校勘本 서지} / 미확인이면 [확인 필요]
- 고증 apparatus: {교감기·역주·고증서}
- 기타 판본·역본: {판본·역본} — 용도: 인용용 / 대조용 / 검색용
- 위치 체계·인용 표기: {예: 권·면 / 장·절 번호 / 사본 folio(r·v) / 문서 번호·행} — 표기 형식만 적고 실제 위치는 카드에
- 전승: {사본·간본 계보, 산일·잔편·후대 집록, 위작·개찬 논란}
- 성격과 편향: {작성 목적, 후원자·소속, 관점, 결을 거슬러 읽을 지점}
- 읽기 방식 기본값: 통독 / 대조
- core-library source_id: {있으면}
- 확인: {사용자 검증일} / 미확인 필드: {목록}
```

## 공구서(서지·연표·사전) — 검증 도구, 인용 원천 아님

전거가 아니라 검증 도구다. 인용 화이트리스트의 원천이 되지 않는다.

- {예: 연대 환산용 연표·역표} — 용도: 연대 환산 근거(`research-profile.md` §3). 서지 [확인 필요]
- {예: 인명·관직 사전} — 용도: 인물 비정 확인
- {예: 역사 지명 사전·게이지티어} — 용도: 지명 비정 확인(`references/gazetteer-linking.md`)

> 공구서는 사실 확인에 쓰고, 본문 인용의 전거로는 1차 사료와 동료 심사를 거친 연구를 댄다.
