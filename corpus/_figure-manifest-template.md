# 도표 매니페스트 양식 (재현 묶음)

> 도표마다 `_workspace/{논문}/{figN}.manifest.md`로 쓴다(`figN` = 파일 스템, 예 `fig2`). 재현 묶음(reproducibility bundle)의 학술판: **①생성 코드 ②실행 환경 ③평문 설명·주장 ④입력 데이터·출처**를 한 장에 묶어, 몇 달 뒤에도 누구나 그 도표를 재현·검증할 수 있게 한다.
>
> 원칙: 지도는 GUI 손질이 아니라 **재현 가능한 스크립트**로 만든다(코드 우선). GUI로 마감한 부분이 있으면 아래 ⑤에 밝힌다. AI가 만든 도표·좌표 제안은 저자 확인 전까지 `[AI잠정]`으로 표시하고 `_provenance.md`에 처리 이력을 남긴다.

## figN — {도표 제목}

- **유형**: 지도 / 표 / 개념도 / 사료 도판 / 네트워크
- **논문 내 위치·역할**: (예: 2장 앞 앵커; `_visuals_spec.md` V1)
- **산출 파일**: `figN_*.svg` / `.png` / `.qgz`

### ① 생성 코드 (재현의 핵심)
- **스크립트**: `{작업공간의 생성 스크립트}.py` (또는 QGIS 처리 모델 `.model3`, 또는 하네스 도구 — 예: `tools/build_network.py`, `tools/georef.py`)
- **재실행**: `python {생성 스크립트}.py {인자}` → `figN_*.svg` 재생성
- (GUI 전용이면 여기를 `[GAP:스크립트]`로 두고, 재현할 수 없음을 밝힌다.)

### ② 실행 환경
- **환경 파일**: `environment.yml` (또는 `requirements.txt`) — 잠금 버전 상속
- **QGIS**: (버전, GUI 마감 시)
- 좌표계: CRS84 / EPSG:4326 (또는 투영 명시)

### ③ 평문 설명·주장 (이 도표가 *무엇을 주장*하는가)
- **보이는 것**: (한 문단. 독자가 무엇을 읽어야 하는가.)
- **뒷받침 주장**: (본문 어느 논지를 시각화하는가 — 04~07 절·문단, P-키.)
- **주의**: (예: 경계가 불확실하면 선이 아니라 띠나 점선으로 그린다 — 불확실성이 시각에 실린다.)

### ④ 입력 데이터·출처 (좌표 정박)
| 입력 파일 | 내용 | 출처 정박 |
|---|---|---|
| `figN_nodes.csv` | 지점 노드 | 표준 노드 스키마(`04_geo_whitelist.md`) |
| `figN_routes.geojson` | 노선 | 위 노드에서 파생 |
| `{배경 데이터}.geojson` | 배경(경계·지형·하천 등) | 데이터셋 이름·버전·라이선스 명시 |

- 모든 좌표는 `04_geo_whitelist.md`에 등록·정박되어 있다(공란·미정박 = verify.py FAIL/GC).
- 배경 데이터(경계·지형 등)는 **출처 데이터셋과 라이선스**(재배포 가능 여부)를 밝힌다.
