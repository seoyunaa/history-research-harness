# 좌표 화이트리스트 양식 (지리 재현성)

> `_workspace/{논문}/04_geo_whitelist.md`로 쓴다. **모든 지도·노선의 좌표는 이 목록과 노드 파일의 출처에서만 나온다.** P-키 화이트리스트(`02_sources_whitelist.md`)의 공간판이다.
>
> 절대 원칙(상속): **좌표·지명 비정(比定)을 지어내지 않는다.** 경위도와 "이 지명 = 여기"라는 판단은 사료 P-키 또는 게이지티어에 정박한다. 찾지 못하면 채우지 말고 `[GAP:좌표]`로 비운다. 그럴듯한 좌표를 지어내는 것은 각주 날조와 같은 실패 유형이다. AI·외부 DB가 낸 좌표는 제안이며, 저자 확인 전까지 `[AI잠정]` 또는 `certainty: low`로 둔다.

---

## 1. 표준 노드 스키마 (모든 point·node 파일 공통)

좌표를 담는 모든 CSV·GeoJSON Point는 아래 필드를 **반드시** 갖는다.

| 필드 | 뜻 | 예 |
|---|---|---|
| `name` / `name_zh` | 표기(glossary 고정) / 원어 표기(열 이름은 도구 호환용 — 한자 외 문자도 여기) | {표기} / {원어 표기} |
| `lon` / `lat` | 경위도 (CRS84 / EPSG:4326, 십진수) | {경도} / {위도} |
| `type` · `segment` | 유형·구간 | {도시} · {구간명} |
| `id_basis` | 비정 근거 지점(고증서·유적) | {고증서가 비정한 현대 지점} |
| **`source`** | **출처(공란 금지)** — 사료 P-키 / 고증서·역주 면수 / 게이지티어 ID | {P-0nn / 고증서 약칭+면수 / 게이지티어:ID} |
| **`certainty`** | `high` · `medium` · `low` | {…} |

- **`source` 공란 = 하드 FAIL**(verify.py). 미상이면 그 행을 `[GAP:좌표]`로 두고 지도에서 뺀다.
- GeoJSON Point는 `properties.source`에 같은 값을 둔다. "통설"·"관례"·"추정"만으로는 약한 출처다 — verify.py가 약한 출처로 집계하니 `certainty: low`로 표시하고 확인하거나 강등한다.

## 2. 출처 계통 (좌표 정박의 원천)

- **1차 사료 좌표**: 사료 P-키 + 발췌 위치. 사료에 나오는 지명은 해당 발췌 카드에 결속한다.
- **고증·역주 비정**: 역주서·고증서의 지명 비정 + 면수. (가공 안 된 텍스트나 자의적 단정은 금지.)
- **역사 게이지티어**: 분야에 맞는 역사 게이지티어(예: World Historical Gazetteer, Pleiades, 지역별 역사 GIS — `research-profile.md` §5, `references/connectors.md`, `references/gazetteer-linking.md`). 근대 실측이 아닌 *역사 비정*이면 게이지티어 ID를 적는다.
- **현대 실측(유적)**: 고고 유적 좌표 — 데이터셋·보고서를 밝힌다.
- **고지도·영인 지도**: 지오레퍼런싱으로 얻은 좌표는 GCP 파일과 매니페스트를 남긴다(`tools/georef.py`, `references/hgis-지오레퍼런싱.md`).

## 3. 노선(LineString)은 노드에서 파생한다

- 노선(`*_routes.geojson` 등)의 정점은 **표준 노드에 정박**한다. 노드에 없는 좌표를 노선에 넣지 않는다(보간·평활 정점은 예외 — 파일명에 `smooth`를 넣거나 매니페스트에 "보간"을 밝힌다).
- verify.py가 노선 정점 중 등록 노드 밖 좌표를 GC로 집계한다. 본선 절점은 0을 지향한다.

## 4. 교차검증 (지명 삼각측량)

| 지명(노드) | 확인 계통 |
|---|---|
| {예: 어느 관문} | {사료 A(P-0nn) · 사료 B(P-0nn) · 게이지티어} 교차 |

## 5. 진행 메모

- 확정/미확정 비정을 추적한다. `certainty: low`·`[GAP:좌표]`는 인용(지도 게재) 전에 확인하거나 강등한다.
- 노드 표기는 `glossary.md`를 따른다(같은 장소의 이표기를 섞지 않는다 — 좌표 라벨도 같다).
- 여러 논문이 공유할 정준 장소는 저자 승인 뒤 `corpus/gazetteer-master.csv`로 승급한다.
